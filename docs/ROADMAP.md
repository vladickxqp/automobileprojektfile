# AutoLife — Роадмап (полный скоуп 1–40)

Принцип: **одна фаза за раз, коммит на фазу, без фейковых данных.**
Каждая фаза = рабочая, проверяемая функциональность.

**Сквозное (закладываем в Phase 0, держим во всех фазах):**
#15 облачная синхронизация · #16 RU/EN/DE · #17 GDPR/безопасность ·
**костяк CarDNA** (VIN-центричность + владение + событийная лента, см. ARCHITECTURE.md §2).

---

## MVP / V1 — релизный минимум

| Фаза | Содержание | Фичи |
|------|-----------|------|
| **0. Фундамент** | Монорепо (pnpm+Turbo), дизайн-система, auth + профиль, **VIN-модель + Ownership + VehicleEvent-лента**, облачная синхронизация, i18n, GDPR-базис | 1, 2, 15, 16, 17 |
| **1. Гараж** | Добавление авто вручную и по VIN, мульти-гараж, дашборд авто | 3, 4, 5 |
| **2. История, документы, расходы** | История обслуживания, загрузка документов, напоминания (ТО/страховка/TÜV/масло), учёт расходов | 6, 7, 8, 9 |
| **3. ИИ-ассистент по симптомам** | Текстовый ассистент: симптом → вероятные причины (RAG) | 10 |
| **4. Диагностика OBD-II** | BLE-подключение к ELM327, чтение и расшифровка ошибок | 11, 12 |
| **5. AutoScore + отчёт о продаже** | Индекс состояния 1–100, цифровой отчёт + публичная ссылка | 13, 14 |

> Порядок осмыслен: сначала копим данные об авто (1–2), затем диагностика (4),
> поверх данных работают ассистент и AutoScore (3, 5).
